# 陣触 ― 戦国群雄記

ブラウザで遊べる戦国時代のシミュレーションゲームです。1560年（桶狭間の直後）の日本を舞台に、大名家の一つを率いて天下統一をめざします。HTMLファイル1枚にまとまっていて、インストールやサーバーは要りません。

## 遊び方

- **ブラウザで遊ぶ**: [claude.ai で公開中のページ](https://claude.ai/artifact/A8FUT835Sor37rcdwickW3)
- **手元で遊ぶ**: [`dist/index.html`](dist/index.html) をダウンロードしてブラウザで開くだけです（約15MB、オフラインで動きます）。

セーブはブラウザに保存されます。

## 主な内容

- **序幕**: 時代を選ぶと、その時代の背景を地図と人物の顔・セリフで紹介します（道三の国盗り、桶狭間、本能寺の変、唐入り）。
- **場面の演出**: 茶会、忍び（暗殺・流言・放火・探り）、家督相続、大名家の滅亡と降伏、謀反、一向一揆、同盟と婚姻、南蛮船と宣教師の来訪、関白・将軍への任官、将軍擁立、天守の完成を、地図と顔・セリフで見せます。
- **逸話**: 敵に塩を送る、三本の矢、槍の又左の帰参、川中島の一騎打ちなど35本。人物が生きていて年が合えば、どの家の話でも場面で見せます（一覧は `ANECDOTES_LIST.txt`）。
- **音**: 琴・尺八・太鼓などの音をブラウザの中で合成した音楽と効果音（設定で切り替え）。
- **地図**: 日本全国をヘックスに分けた地図（約530ヘックス・158城）。地形、国、城の支配域があります。
- **内政・経済**: 石高と商業、年貢の率、内政への投資、新田開発、城の普請（石垣〜天守）、楽市楽座。金山・銀山と各地の特産品、南蛮船と唐船の貿易。
- **知行と家臣団**: 家臣に城を与えて城持ちにし、陪臣・与力・後継ぎを定める。降った大名は本領を安堵して外様に。恩賞（感状・加増・取り立て）、朝廷への官位の推挙、守護代の任命。
- **軍事**: 鉄砲・名物・軍団の編成と合流・分割。城持ちの領は方針（攻略・防衛・軍備増強）に従って領主が動かす。
- **合戦**: 野戦と攻城戦の戦術画面。攻城戦は月をまたいで続きます。
- **外交**: 同盟、婚姻、降伏勧告に加え、朝廷・幕府・商人とのやり取りがあります。
- **武将**: 600人あまり。肖像画、略歴、特性（水軍、忍者、剣豪、算勘、外交、僧 など）があります。
- **唐入り**: 天下統一のあとに続く幕間と、1592年から始まるシナリオ「唐入り」。海を渡る兵と兵糧、朝鮮水軍、義兵、明の援軍、講和を描きます。

## ビルド

Node.js（18以上）が必要です。

```sh
npm install
npx tsc -p .           # 型チェック
node tools/build.mjs   # dist/index.html を生成
```

`tools/e2e*.mjs` は Playwright を使った画面のテストです（Playwright は別に入れてください）。

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `src/engine` | ゲームのルール（戦闘、AI、経済、外交、唐入り など） |
| `src/ui` | 画面（Canvas の地図、各パネル、CSS） |
| `src/data` | 武将・城・地図のデータ、埋め込み済みの肖像画と場面絵 |
| `tools` | ビルド、地図生成、テストのスクリプト |
| `assets` | 場面絵と地図タイルの元画像 |
| `SPEC_v1.1.md` | 仕様と更新の記録 |
| `GENERALS_*` / `PORTRAITS_*` / `TRAITS_LIST.txt` | 武将・肖像画・特性の一覧と、絵の注文書 |

肖像画の元の画像（PNG、約150MB）はリポジトリに入れていません。ゲームで使う縮小版は `src/data/portraits.ts` に埋め込んであるので、ビルドには困りません。

## データの出典

- 海岸線と地形の元データ: [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）、npm パッケージ `world-atlas` 経由で使っています。
- 人物の能力値、略歴、ゲームの中の出来事は、史実をもとにしたゲーム上の創作です。
